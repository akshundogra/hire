SLIDE 05 / 10 Execution Roadmap

First 90 Days: 30 / 30 / 30 Roadmap

No campaigns start before there is a trustworthy attribution and measurement baseline.

  • 01
    Days 1–30 — Discovery & Audit See the Intent
    Stakeholder interviews with sales & leadership: What defines a qualified lead? What data does sales need before discovery calls? Technical audit of CRM, GA4, Search Console, Google Ads, tracking, and 24-month pipeline history to identify quick wins (missing tracking, tagging errors). The attribution window is particularly critical: A default 30-day conversion window is practically meaningless for MDIS's 6-to-12-month decision cycles — the last touch before a meeting is almost never the true driver of conversion over such a long buyer journey. That is precisely why self-reported attribution in lead forms is essential. 📦 Output: Prioritised measurement & tooling roadmap. Self-reported attribution field in every form + CRM origin tracking.
  • 02
    Days 31–60 — Base System Build Enrich It
    Backend System: Lead and account scoring v1 in CRM (firmographics 50–500 DACH accounts & intent signals), rep routing SLA workflows, initial nurture sequences, self-reported attribution, and conversion-value data layer.

    Parallel Inbound Track: Initial SEO optimization from audit (H1 tags, technical SEO, landing pages for pull keywords like 'SAP ECC Alternative'), initial content clusters live (SAP migration topics), initial paid search campaigns on existing search intent, and LinkedIn content for X.One executive visibility. Inbound runs in parallel with system build.     📦 Output: Live scoring v1, rep routing SLA definition, daily target-to-SQL dashboard.
  • 03
    Days 61–90 — Optimization & Scale Act On It
    Backend & Data: Calibrate initial scoring based on real sales feedback, live telemetry dashboard with real pipeline numbers, rebalance budgets across Google/LinkedIn/test channels based on first-touch data.

    Scale Inbound: Fully roll out SAP ECC migration campaign across all topic clusters (HCM→Personio, Concur→Circula, SRM→Purchasing, BusinessObjects→Dashboard) with S/4HANA TCO comparison. Increase content cadence.

    Activate Outbound: Target account lists for X.One (CFO/Executive management), buying group mapping per account, GDPR-compliant multi-channel sequences.

    Launch Agents: First version of Visibility Agent and Paid-Performance Agent live under human-in-the-loop approval.     📦 Output: SAP 2030 landing page, target account list, approved outbound workflow, test results & stop criteria.

SLIDE 06 / 10 System Architecture

Governed Multi-Agent Operating System

Four specialized GTM agents operating under human-in-the-loop approval before any external action.

AGENT 1 · VISIBILITY
Visibility Agent
Monitors SEO rankings, AI search visibility (GEO), and competitor positioning continuously.
AGENT 2 · PERFORMANCE
Paid-Performance Agent
Detects ad waste, budget anomalies, and scaling opportunities in real-time.
AGENT 3 · EXECUTION
Execution Agent
Generates landing pages, content variants, and ABM assets in an automated recycling system.
AGENT 4 · HANDOFF
Handoff Agent
Generates pre-call dossiers and hands off qualified accounts to sales under strict SLAs.
Governance Rule: Autonomous reading & analysis; strict human-in-the-loop approval required before any external contact, budget modification, or publishing action. Every external touchpoint is documented in a GDPR-compliant manner — consent logic, opt-out rights, and cold outreach rules under German law strictly enforced.
